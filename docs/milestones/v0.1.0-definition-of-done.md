# v0.1.0 definition of done

> Status: **Draft for owner approval** (2026-10-09). Names use the placeholder
> product name ("Coffee", command `coffee`).

v0.1.0 is done when **every command below passes on Windows, macOS and Linux
in CI** (the `verify` and `acceptance` jobs of `.github/workflows/ci.yml`, Node
from `.nvmrc`), and the release checklist at the end is complete.

## Scope recap

Step file parser and validator, action registry with all built-in actions,
context and variables, runner, event stream over the protocol, and a CLI that
runs step files against the demo app and prints results. Chromium only.

## Commands

Run from the repository root on each of the three systems:

```sh
pnpm install --frozen-lockfile
pnpm exec playwright install --with-deps chromium   # browser download; --with-deps matters on Linux
pnpm verify             # type check, lint, format check, unit tests
pnpm test:integration   # engine and protocol tests against the demo app in Chromium
pnpm acceptance         # the CLI commands below, as a script that checks exit codes and output
```

`pnpm acceptance` starts the demo app on port 4310, then runs these commands
and checks each exit code and the listed output. They can also be run by hand
(`pnpm cli` runs the built CLI):

## Integration tests (`pnpm test:integration`)

Besides running the samples in-process, these protocol tests spawn the engine as
a client would:

- **Handshake**: compatible `initialize` succeeds; any request before it gets
  `NotInitialized`; an incompatible version gets `IncompatibleProtocol` and the
  process exits with code 3.
- **Events**: for `tests/flows.test.yaml`, the event sequence (types, `seq`,
  `testId`, `stepId`, `section`) matches a checked-in expectation; every
  `stepStarted.params` is the canonical long form.
- **Cancellation**: `cancelRun` during a 30-second `wait.element` ends the step
  within 2 seconds with `Cancelled`; `after` steps run; `testFinished` has
  status `cancelled`.
- **Page states**: each step produces `screenshotReady` (PNG exists) and
  `snapshotReady`; `openSnapshot` opens the snapshot without error.
- **Run folder**: the layout of [ADR 0015](../adr/0015-results-layout.md);
  `events.ndjson` equals the events received over the protocol.
- **Schemas**: every message sent in these tests validates against the JSON
  Schemas in `packages/protocol/schema/`.
- **stdout hygiene**: a user action calling `console.log` does not corrupt the
  protocol stream.
